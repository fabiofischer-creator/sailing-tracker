1 GitHub Repository erstellen & Seite hochladen

  1. Gehe zu github.com/new und erstelle ein Repository namens sailing-tracker
  2. Auf Public setzen → "Create repository"
  3. Diese HTML-Datei (sailing-tracker.html) umbenennen in index.html und hochladen
  4. Einen media/ Ordner erstellen: "Add file" → "Create new file" → Dateiname: media/.gitkeep → Commit
  5. Unter Settings → Pages → Source: "Deploy from branch: main" aktivieren
  6. Deine URL lautet dann: https://DEIN_USERNAME.github.io/sailing-tracker

2 Firebase Firestore einrichten (GPS & Tagebuch)

  1. Öffne die Firebase Console → Firestore
  2. Klicke "Datenbank erstellen" → Modus: Produktionsmodus → Region wählen (z. B. europe-west1)
  3. Unter Regeln folgende Regeln einfügen und veröffentlichen:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /gps/{doc} {
      allow read: if true;   // öffentlich lesbar
      allow write: if true;  // Apps Script darf schreiben
    }
    match /log/{doc} {
      allow read:  if true;  // öffentlich lesbar
      allow write: if false; // nur über Firebase Console
    }
  }
}

Zwei Collections werden automatisch angelegt sobald Daten kommen: gps und log.

3 Google Apps Script — GPS direkt in Firestore speichern

Dieses Script empfängt GPS-Daten von GPSLogger und speichert sie in Firestore (kein Google Sheets nötig).

  1. Gehe zu script.google.com → "Neues Projekt"
  2. Den folgenden Code einfügen:
var API_KEY = 'AIzaSyAcAG2xW3urumaNLpsRaLoh7698TMysSqc';
var PROJECT = 'sailing-tracker-b9acb';
var FS_URL  = 'https://firestore.googleapis.com/v1/projects/'
            + PROJECT + '/databases/(default)/documents/gps?key=' + API_KEY;

function doPost(e) { return saveGPS(e.parameter); }
function doGet(e)  { return saveGPS(e.parameter); }

function saveGPS(p) {
  var body = JSON.stringify({ fields: {
    timestamp: { stringValue: new Date().toISOString() },
    lat:       { doubleValue: parseFloat(p.latitude  || '0') },
    lng:       { doubleValue: parseFloat(p.longitude || '0') },
    speed:     { doubleValue: parseFloat(p.speed     || '0') },
    heading:   { doubleValue: parseFloat(p.bearing   || '0') },
    note:      { stringValue: p.note || '' }
  }});
  UrlFetchApp.fetch(FS_URL, {
    method: 'post', contentType: 'application/json', payload: body
  });
  return ContentService.createTextOutput('OK');
}
  1. Datei speichern → "Bereitstellen" → "Neue Bereitstellung" → Typ: "Web-App"
  2. Ausführen als: Ich | Wer hat Zugriff: Jeder
  3. Bereitstellen → Script-URL kopieren (benötigst du im nächsten Schritt)

4 GPSLogger App konfigurieren

  1. GPSLogger aus dem Play Store installieren
  2. App öffnen → Menü (☰) → Logging Details → Log to custom URL aktivieren
  3. URL eintragen (Script-URL aus Schritt 3 + Parameter):
https://script.google.com/macros/s/DEINE_SCRIPT_ID/exec
  ?latitude=%LAT
  &longitude=%LON
  &speed=%SPD
  &bearing=%DIR
  &altitude=%ALT
  1. Unter Performance & Accuracy: Logging-Intervall auf 10–30 Minuten setzen (spart Starlink-Daten)
  2. GPSLogger im Hintergrund laufen lassen — sendet automatisch per Starlink
